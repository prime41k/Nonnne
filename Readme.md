

# Nonnne

Эта штука спасает от ошибок, когда переменная вдруг оказывается пустой. Забудь про бесконечные проверки "если не ноль, то...". Просто оберни значение и работай спокойно.

## Зачем это нужно

Обычно код ломается, если ты забыл проверить данные. Nonnne берет эту рутину на себя. Если значения нет — он тихо вернет запасной вариант, а не уронит всё приложение.

## Как пользоваться

Скопируй файл `nonnne.py` к себе в проект. Ничего устанавливать не надо.

Простой пример:

```python
from nonnne import Maybe

# Допустим, мы ищем пользователя
user = Maybe(find_user(123))

# Если пользователя нет, код не упадет, а вернет "Гость"
name = user.name.unwrap("Гость")
```

## Что умеет

- **Безопасный доступ**: Можно смело писать `data.user.profile.age`, даже если чего-то не хватает.
- **Запасные варианты**: Метод `unwrap` подставит дефолтное значение, если данных нет.
- **Цепочки**: Можно строить длинные цепочки вызовов, не боясь ошибок.

## Примеры из жизни

Работа со сложными словарями:

```python
from nonnne import get_path

config = {"server": {"host": "localhost"}}
host = get_path(config, "server", "host").unwrap("127.0.0.1")
```

Безопасные вычисления:

```python
from nonnne import safe_call

# Даже если функция ошибется, программа продолжит работу
result = safe_call(lambda: 10 / 0).unwrap(0)
```

## Итог

Nonnne делает код чище и надежнее. Ты тратишь меньше времени на отладку и больше на реальные задачи.
